# Medlaser

Окно управления платой WeAct STM32G431. Плата задаёт заряд конденсатора, поджиг, мощность и следит за расходом воды в чиллере. На компьютер ставится только программа окна: прошивка уже записана в плату.

## Что нужно

- Ноутбук с Windows 10 или 11
- Python 3
- Кабель с линиями данных. Надёжный вариант — Type-C платы в USB-A ноутбука через простой переходник. Прямой Type-C–Type-C часто не даёт ни питания, ни данных: нужен обычный кабель USB 2.0, не зарядный
- Файл `host/laser_gui.py` из этого репозитория

## Установка на Windows

1. Поставь Python 3 с [python.org](https://www.python.org/downloads/windows/). В установщике отметь **Add python.exe to PATH**.
2. Скачай этот репозиторий и открой командную строку в его папке.
3. Поставь библиотеку порта и запусти окно:

```bat
py -3 -m pip install -r host/requirements.txt
py -3 host/laser_gui.py
```

Если команда `py` не находится, замени её на `python`.

## Порт

Подключи плату и открой диспетчер устройств. Она должна появиться как **USB Serial Device** или **STM32 Virtual COM Port**, имя вида `COM3`. В окне программы нажми **Обновить**, выбери этот `COM` и нажми **Открыть**. Порты Bluetooth и других адаптеров не подходят.

Если устройство с жёлтым знаком и кодами VID `0483`, PID `5740`, поставь драйвер ST **Virtual COM Port** с сайта STMicroelectronics и переткни кабель.

Синий светодиод на плате показывает, на каком этапе связь:

- частое мигание — прошивка работает, компьютер порт ещё не открыл;
- медленное, примерно раз в секунду — Windows плату видит.

## Как пользоваться окном

1. **Открыть** порт платы.
2. Через секунду в строке **Расход, л/мин** появится число, если сенсор воды подключён.
3. Выставь частоту, мощность, заряд конденсатора, поджиг и число импульсов. Ноль в поле импульсов означает серию до нажатия **Stop**.
4. Включи **Разрешить пуск**.
5. **Start** запускает серию, **Stop** останавливает.

Расход воды только показывается в окне и пуск не блокирует. Если связь с ноутбуком пропадёт дольше чем на полторы секунды, серия сама остановится. Педаль этого сторожа не ждёт: она пускает и останавливает сама, но галка **Разрешить пуск** должна быть включена.

Закрытие окна посылает Stop.

На macOS те же команды через `python3`, а порт в списке называется `/dev/cu.usbmodem…`.

## Прошивка платы

Один раз, если плата ещё пустая. Файл прошивки — `build/medlaser.hex`. Запиши его программой STM32CubeProgrammer через ST-Link в разъём SWD платы. После этого плата общается с компьютером по своему Type-C, отдельный переходник UART не нужен.

## Подключение платы

Ноги STM32 идут на гребёнку штатной платы управления, до оптопар. На шлейф лазера их не сажать. Пины **5V** и **VCC** гребёнки не подключать. Земля STM32 соединяется с землёй гребёнки.

| Нога | Назначение |
| --- | --- |
| PA0 | Заряд конденсатора. В покое 3,3 В, импульс тянет к земле |
| PA1 | Поджиг. В покое 3,3 В, импульс тянет к земле |
| PA4 | Мощность, ШИМ |
| PA5 | Педаль: в покое 3,3 В, нажатие замыкает на землю |
| PA6 | Импульсы сенсора расхода воды |
| GND | Земля гребёнки |

Сенсор воды SEN-HZ21WA: красный провод на 5 В платы WeAct, чёрный на землю. Жёлтый провод — это импульс около 5 В, на PA6 напрямую его подавать нельзя. Поставь делитель: 2,2 кОм от жёлтого провода до PA6 и 3,3 кОм от PA6 на землю. На ноге при этом около 3 В. Десять импульсов в секунду — 1 л/мин.
